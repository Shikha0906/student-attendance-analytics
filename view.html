🔄 MapReduce vs Direct

Both aggregation methods produce identical results. Toggle use_mapreduce=True on any analytics call to use the MapReduce-style path (map: emit (status, 1) → shuffle/group → reduce: sum by key).

daily_totals(date, use_mapreduce=False)      # Direct aggregation
daily_totals(date, use_mapreduce=True)       # MapReduce aggregation
course_wise_totals(course_id, use_mapreduce=True)
average_attendance_rate(course_id, use_mapreduce=True)
